## Buoy

[Buoy](https://github.com/coderlambda/buoy-tmux) is a desktop client for local and remote
tmux workspaces on macOS, Windows, and Linux.

- Stable tmux connections and reliable SSH reconnection
- In-place previews for files and self-contained HTML pages
- Automatic recognition of localhost service addresses
- SSH tunnels that open on demand and recover after reconnecting
- Drag-and-drop file and folder uploads to the terminal's current directory
